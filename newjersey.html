Advanced: live NJ Transit buses

NJ Transit is scheduled by default (no setup). Rail covers every line in the state; buses cover the bundled trunk routes only. Paste an njt-worker.js URL to switch buses to live — that unlocks all 263 routes. Your API key lives in the Worker, never in this browser.

Live trains need no Worker. NJT's rail API allows direct browser calls, so the login below is enough for live positions on all 17 lines. It is stored only in this browser, on this device - a Worker secret is more private, so prefer the Worker above if you have it running.
