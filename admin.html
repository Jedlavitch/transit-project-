Save to this screen configures this one device. Copy config.js gives you the same settings as a file — paste it over the block in config.js and redeploy, and every customer's board picks them up with nothing for them to enter.

Before you rely on this

These values live in this browser and are readable by anyone who opens developer tools on this screen. Fine for a kiosk you control; not a place for a credential you would mind a customer finding. See SELLING.md.
