Sign-in is built but has no server behind it yet, so there is nothing to sign in to. It needs account-worker.js deployed with a KV namespace bound as ACCOUNTS and an email API key — the steps are in ACCOUNTS.md. Paste the Worker URL into acctUrl in config.js and this section turns itself on everywhere, with no other change.

Everything else on this page works without it.
