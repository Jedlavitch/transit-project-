Set your admin password

This hides the operator-only settings on a customer's board — Worker URLs, feed codes, the spreadsheet mirror. Type a password you'll remember; this page turns it into the value that goes in the code.

Paste this into admin.js, line 34:

  1. Open admin.js and replace const ADMIN_SHA256 = ""; with the value above
  2. Commit and deploy
  3. Unlock a screen once by visiting index.html?admin=YOUR-PASSWORD
  4. Lock it again with index.html?admin=off

Your password never leaves this page. The hashing happens in your browser — nothing is sent anywhere, and the file only ever contains the hash, so reading the deployed source doesn't reveal your password.

But a hash is not a lock. Anyone can take the hash from the source and try guessing against it offline, as fast as their machine allows. A short or common password falls in seconds. Use several unrelated words.

And this hides controls, it doesn't protect secrets. The whole site ships to the browser, so anyone in devtools can unhide the fields. Don't put anything behind it that would actually hurt to leak.
